# Objective

Implement the canonical Accommodation Application Result contracts.

Application Results define the outputs returned by the Accommodation Engine.

They represent business-oriented application contracts.

They are not supplier contracts.

They are not presentation contracts.

---

# Architectural Principle

Application Services return Application Results.

Application Results compose Application Models.

Presentation contracts are constructed later by View Model Providers.

The Accommodation Engine shall expose only Application Results.

# Design Principle

Application Results wrap Application Models.

Example

```text
AccommodationSearchResult

    accommodations[]

    metadata
```

The result owns the collection.

The Accommodation Model remains unchanged.

# Milestone Outcome

Upon successful completion, the Accommodation Engine shall expose canonical Application Result contracts that encapsulate Accommodation Models and provide a stable application boundary for all higher-level services.

These contracts become the only outputs returned by the Accommodation Engine and prepare the platform for Provider Registry Behaviour, Hotelbeds integration, Package Builder orchestration and future multi-provider accommodation capabilities.
