# Objective

Implement the canonical Provider Capability Framework for the Accommodation Engine.

The framework formalises provider capabilities as immutable, typed application models that describe **what a provider can do**, independent of any supplier implementation.

The Accommodation Engine shall discover providers through capabilities rather than by provider identity.

---

# Architectural Principle

The Accommodation Engine shall never ask:

> "Is this Hotelbeds?"

Instead it shall ask:

> "Which providers support this capability?"

Capability discovery becomes the canonical mechanism for provider orchestration.

# Capability Descriptor

Create

```typescript
interface AccommodationProviderCapability {

    readonly identifier:
        AccommodationProviderCapabilityId;

    readonly type:
        AccommodationProviderCapabilityType;

    readonly name: string;

    readonly description: string;

    readonly version: string;

    readonly enabled: boolean;

    readonly deprecated: boolean;

    readonly experimental: boolean;

    readonly features:
        ProviderFeatureSet;

}
```

Capabilities are immutable.

Capabilities represent business functionality.

---

# Capability Identifier

Create

```typescript
type AccommodationProviderCapabilityId = string;
```

The identifier provides a stable reference independent of display names.

---

# Capability Types

Create

```typescript
enum AccommodationProviderCapabilityType {

    SEARCH,

    DETAILS,

    AVAILABILITY,

    CONTENT,

    IMAGES,

    RATES

}
```

These become canonical application capability types.

---

# Provider Feature

Capabilities may expose individual features.

Example

```typescript
interface ProviderFeature {

    readonly id: string;

    readonly name: string;

    readonly description: string;

}
```

Examples

- Radius Search
- Free Text Search
- Multi-Room Search
- Cached Content
- High Resolution Images
- Live Rates

Features describe implementation richness.

Capabilities describe business functionality.

---

# Provider Feature Set

Create

```typescript
interface ProviderFeatureSet {

    readonly features:

        ReadonlyArray<ProviderFeature>;

}
```

Collections shall remain immutable.

---

# Provider Capability Set

Create

```typescript
interface ProviderCapabilitySet {

    readonly capabilities:

        ReadonlyArray<
            AccommodationProviderCapability
        >;

}
```

# Provider Registry

Expand the registry.

Example

```typescript
findProviders(

    capability:
        AccommodationProviderCapabilityType

)

capabilities(

    providerId

)

features(

    providerId

)

supports(

    providerId,

    capability

)
```

The registry owns provider discovery.

The Accommodation Engine shall not iterate over providers.

---

# Capability Discovery

Capability discovery shall be:

- Type-safe
- Immutable
- Supplier independent
- Deterministic

The registry shall remain the single source of truth.

---

# Milestone Outcome

Upon successful completion, the Accommodation Engine shall expose a fully typed Provider Capability Framework that enables capability-driven provider discovery and feature negotiation while remaining completely independent of supplier implementations.

This milestone completes the architectural foundation of the Accommodation Engine.

All future provider integrations, including Hotelbeds, shall integrate through this framework without requiring changes to the Accommodation Engine itself.
