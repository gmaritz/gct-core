# Objective

Integrate the Homepage Showcase View Model Provider with the Homepage Merchandising Service.

This milestone completes the application-to-presentation flow by replacing internally generated placeholder merchandising data with the output supplied by the Homepage Merchandising Service.

The Homepage UI shall remain visually identical.

No presentation behaviour shall change.

---

# Architectural Principle

The Homepage Showcase View Model Provider is a presentation mapper.

Its only responsibility is to transform application-layer business results into frontend View Models.

The provider shall never:

- perform merchandising
- apply business rules
- select journeys
- calculate pricing
- access Hotelbeds
- access repositories
- render presentation

# Provider Responsibility

The Homepage Showcase View Model Provider shall:

- Request HomepageMerchandisingResult.
- Map HomepageMerchandisingResult to HomepageShowcaseViewModel.
- Build JourneyCardViewModels.
- Build EditorialPanelViewModel.
- Build shared presentation View Models.
- Return a complete HomepageShowcaseViewModel.

No business decisions are permitted.

---

# Mapping Responsibility

The provider shall perform explicit mapping.

Example

```text
HomepageMerchandisingResult

↓

EditorialContent

↓

EditorialPanelViewModel
```

```text
JourneySelection

↓

JourneyCardViewModel
```

```text
MerchandisingMetadata

↓

HomepageMetadataViewModel
```

Mapping shall remain explicit and readable.

No implicit object spreading.

No presentation logic inside application services.

---

# Controller Responsibilities

The Frontend Controller shall:

- Request HomepageShowcaseViewModel from the provider.
- Pass the View Model directly to the view.
- Remain free of mapping logic.
- Remain free of merchandising logic.

No controller behaviour changes.

---

# Milestone Outcome

Upon successful completion, the Homepage Showcase shall obtain all merchandising information through the Homepage Merchandising Service via the Homepage Showcase View Model Provider.

The presentation layer will become completely independent of merchandising implementation while remaining ready for future integration with the Accommodation Engine, Package Builder and Hotelbeds.

This milestone completes the initial Application-to-Presentation architecture for the Homepage Showcase.
