# Objective

Implement the Accommodation Composition Adapter.

The adapter transforms canonical Accommodation application results into JourneyAccommodation models for the Journey Aggregate.

The adapter performs transformation only.

It owns no business rules.

It owns no provider integrations.

---

## Included

- Composition context
- Transformation logic
- Immutable result contracts
- Unit tests
- Barrel exports

- Provider mapping
- Pricing
- Journey orchestration
- Policy evaluation

# Responsibilities

The adapter shall

- request accommodation capabilities
- aggregate canonical application results
- transform canonical accommodation into JourneyAccommodation
- return immutable collections

The adapter shall never

- call providers directly
- implement business rules
- validate journeys
- calculate pricing
- perform orchestration

---

# Composition Context

Create

```typescript
AccommodationCompositionContext
```

Purpose

Provide only the information required for accommodation composition.

Typical fields

- destination
- travel dates
- traveller count
- room requirements
- accommodation preferences

Remain immutable.

---

# Composition Flow

```text
AccommodationCompositionContext

        │

        ▼

Accommodation Discovery Service

        │

        ▼

Accommodation Content Service

        │

        ▼

Accommodation Inventory Service

        │

        ▼

Accommodation Rate Service

        │

        ▼

Accommodation Composition Adapter

        │

        ▼

JourneyAccommodation
```

All services return canonical application results.

No provider contracts shall be exposed.

---

# Failure Isolation

Service execution shall use

```typescript
Promise.allSettled()
```

Individual service failures shall be isolated.

The adapter shall determine whether sufficient information exists to compose JourneyAccommodation.

---

# Result

Return

```typescript
ReadonlyArray<
    JourneyAccommodation
>
```

No provider models.

No application service results.

Only canonical Journey models.

# Milestone Outcome

Upon successful completion, GCT Core shall expose an Accommodation Composition Adapter that transforms canonical accommodation application results into immutable JourneyAccommodation models.

The adapter forms the bridge between the Accommodation Capability Suite and the Journey Composition Engine while remaining completely independent of providers, pricing, validation, policy evaluation and orchestration.
