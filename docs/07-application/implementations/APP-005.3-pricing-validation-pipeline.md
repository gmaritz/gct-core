# Objective

Implement the canonical Pricing Validation Pipeline.

The pipeline validates pricing requests and commercial integrity before any pricing calculations are performed.

Validation is layered to separate structural correctness from commercial correctness and financial integrity.

---

# Validation Models

Provide immutable validation contracts:

- PricingValidationResult
- PricingValidationError
- PricingValidationErrorCode
- PricingValidationStage

Validation models conform to APP-001D.

---

# Pricing Request Validator

Responsibilities:

- validate request
- validate required fields
- validate currency
- validate pricing inputs
- validate structural completeness

Does not validate commercial rules.

---

# Commercial Validator

Responsibilities:

- validate discounts
- validate promotions
- validate markups
- validate commissions
- validate fee structure
- validate taxation configuration

Does not perform calculations.

---

# Pricing Integrity Validator

Responsibilities:

- validate pricing breakdown
- validate totals
- validate component consistency
- validate currency consistency
- validate financial completeness

The validator verifies financial integrity only.

---

# Quote Readiness Validator

Responsibilities:

- validate quote metadata
- validate quote lifecycle
- validate expiry
- validate quotation completeness

This validator determines whether pricing is suitable for quotation.

---

# Validation Pipeline

Create:

```typescript
PricingValidationPipeline
```

Responsibilities:

- execute validators in order
- aggregate validation results
- stop on critical validation failures
- return immutable PricingValidationResult

Validators shall be constructor injected.

---

# Dependency Injection

Inject:

- PricingRequestValidator
- CommercialValidator
- PricingIntegrityValidator
- QuoteReadinessValidator

No validator may instantiate another validator.

---

# Immutability

Validation contracts shall expose:

- readonly properties
- readonly collections

No mutable references may escape validation results.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a layered Pricing Validation Pipeline that validates structural correctness, commercial correctness, pricing integrity and quotation readiness through immutable validation contracts.

The pipeline establishes the commercial validation foundation of the Pricing Capability while remaining independent of pricing calculations, policy evaluation and presentation.
