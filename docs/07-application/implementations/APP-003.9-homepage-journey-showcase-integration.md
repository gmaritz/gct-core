# Objective

Integrate the completed Journey Composition capability into Homepage Merchandising.

The homepage shall display featured Journey cards using the canonical Journey presentation pipeline.

No Journey business logic shall exist inside Homepage Merchandising.

---

# Scope

## Included

- Homepage Journey Showcase Service
- Journey showcase result
- Homepage provider integration
- Unit tests
- Barrel exports

## Excluded

- Journey composition logic
- Provider integrations
- Controllers
- EJS templates
- Pricing
- Reservations

# Homepage Journey Showcase Service

Create

```typescript
HomepageJourneyShowcaseService
```

Responsibilities

- request featured journeys
- invoke JourneyCompositionService
- invoke JourneyPresentationMapper
- invoke JourneyViewModelProvider
- return homepage showcase models

The service shall remain stateless.

# Milestone Outcome

Upon successful completion, GCT Core shall expose featured Journey cards on the homepage through the canonical Journey presentation pipeline.

Homepage Merchandising remains responsible for presentation orchestration, while the Journey Composition Engine remains responsible for business orchestration. Both capabilities remain independently deployable, testable and maintainable.
