# Objective

Implement the canonical Payment Provider Integration layer.

The integration layer coordinates payment operations through provider-independent gateway contracts.

The Application Layer remains completely independent of payment provider SDKs.

---

# PaymentGateway

The gateway defines the canonical provider contract.

Supported operations:

- AUTHORIZE
- CAPTURE
- SETTLE
- REFUND
- STATUS

No provider-specific terminology shall appear in the interface.

---

# PaymentGatewayRequest

Immutable request.

Contains:

- payment reference
- reservation reference
- provider reference
- operation
- payment method
- currency
- amount
- metadata

---

# PaymentGatewayResult

Immutable result.

Contains:

- success
- provider reference
- transaction reference
- authorization status
- capture status
- settlement status
- payment status
- warnings
- metadata

The result normalizes provider responses into canonical payment concepts.

---

# PaymentProviderContext

Contains immutable execution context for provider operations.

Includes:

- payment aggregate
- gateway request
- operation
- metadata

---

# PaymentProviderIntegrationService

Responsibilities:

1. Create gateway request.
2. Invoke PaymentGateway.
3. Normalize provider response.
4. Return immutable PaymentGatewayResult.

Business failures are returned as result objects.

Unexpected technical exceptions are allowed to propagate.

---

# Supported Operations

## AUTHORIZE

Request payment authorization.

---

## CAPTURE

Capture previously authorized payment.

---

## SETTLE

Finalize settlement.

---

## REFUND

Initiate refund.

---

## STATUS

Retrieve payment status.

---

# Milestone Outcome

Upon successful completion, GCT Core shall expose a deterministic, provider-independent Payment Provider Integration layer that coordinates payment operations through immutable gateway contracts.

The integration layer establishes the canonical boundary between the Application Layer and Infrastructure Layer, ensuring that payment provider implementations remain replaceable without affecting application architecture.
