# Objective

Implement the canonical Pricing Model Library.

The Pricing Model Library provides immutable financial models shared across the Pricing Capability and future commercial capabilities.

The library establishes the canonical financial language of GCT Core.

# Model Architecture

The Pricing Model Library establishes the canonical financial model.

```text
Money

        │

        ▼

Commercial Components

        │

        ▼

Pricing Breakdown

        │

        ▼

Pricing Summary

        │

        ▼

Pricing Aggregate
```

All commercial values originate from immutable Money objects.

---

# Money Models

## Money

Canonical immutable monetary value object.

Represents:

- amount
- currency

Responsibilities:

- immutable monetary representation
- equality support
- defensive construction

Money shall not perform calculations.

---

## Currency

Canonical currency enumeration.

Examples:

- ZAR
- USD
- EUR
- GBP

Extensible.

---

## Exchange Rate

Represents exchange-rate information.

Initial implementation is structural only.

No exchange calculations are performed.

---

# Taxation Models

Provide canonical taxation structures.

Includes:

- Tax
- Tax Breakdown
- Tax Type

Taxation remains calculation-independent.

---

# Commercial Models

Provide reusable commercial components.

Includes:

- Fee
- Discount
- Markup
- Commission
- Promotion

These models describe commercial values.

They perform no calculations.

---

# Pricing Models

Provide complete pricing structures.

Includes:

- Pricing Summary
- Pricing Breakdown
- Pricing Line Item
- Pricing Total
- Pricing Metadata

These models are consumed by the Pricing Aggregate.

---

# Quotation Models

Provide reusable quotation contracts.

Includes:

- Quote
- Quote Item
- Quote Status
- Quote Metadata

Quotation orchestration is implemented later.

---

# Immutability

Every model shall expose:

- readonly properties
- readonly collections
- immutable construction

No mutable references may escape public contracts.

---

# Dependency Rules

The model library depends only upon:

- canonical value objects
- TypeScript language features

The library shall never depend upon:

- providers
- services
- validators
- policies
- calculators
- presentation

# Milestone Outcome

Upon successful completion, GCT Core shall expose a canonical Pricing Model Library that provides immutable financial models for pricing, quotations and future commercial capabilities.

The library establishes the shared financial language of the platform by defining provider-independent value objects and commercial models that can be reused consistently across Pricing, Payments, Invoicing, Refunds and Financial Reporting.
