# Objective

Implement the canonical Quote Integration layer.

The Quote Integration layer transforms successful Pricing Engine results into immutable provider-independent Quote artefacts.

The layer establishes quotations as first-class commercial objects within GCT Core.

---

# Scope

## Included

- Quote integration service
- Quote context
- Quote result
- Quote factory
- Quote lifecycle metadata
- Unit tests
- Barrel exports

---

## Excluded

- Reservation creation
- Supplier communication
- Booking confirmation
- Payment processing
- Inventory reservation

# QuoteContext

Create:

```typescript
QuoteContext
```

Contains:

- PricingEngineResult
- traveller summary
- journey summary
- pricing summary
- quotation metadata
- creation timestamp

Immutable.

---

# QuoteReference

Create:

```typescript
QuoteReference
```

Represents the canonical quote identifier.

Examples:

- quotation number
- external reference
- customer reference

Immutable.

---

# QuoteLifecycle

Represents quotation lifecycle information.

Includes:

- created
- expires
- accepted
- expired
- withdrawn

No business behaviour.

---

# QuoteFactory

Create:

```typescript
QuoteFactory
```

Responsibilities:

- construct immutable Quote
- assign lifecycle metadata
- assign quotation reference
- preserve pricing snapshot

The factory performs no pricing calculations.

---

# QuoteIntegrationService

Create:

```typescript
QuoteIntegrationService
```

Responsibilities:

- consume PricingEngineResult
- construct QuoteContext
- invoke QuoteFactory
- return QuoteResult

The service shall never:

- create reservations
- communicate with suppliers
- reserve inventory
- process payments

---

# QuoteResult

Contains:

- success indicator
- Quote
- warnings
- lifecycle metadata

Immutable.

---

# Dependency Injection

Inject:

- PricingEngine
- QuoteFactory

The integration service shall construct no dependencies internally.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a provider-independent Quote Integration layer that transforms Pricing Engine results into immutable Quote artefacts with lifecycle metadata.

The Quote Integration layer completes the Pricing Capability by introducing quotations as first-class commercial objects while maintaining a strict separation between pricing, reservations, supplier integrations and payments.
