# Objective

Implement the canonical Pricing Presentation Pipeline.

The pipeline transforms immutable Pricing aggregates into presentation models and UI-ready view models without introducing business logic.

The presentation layer communicates commercial outcomes while remaining independent of pricing calculations.

---

# Scope

## Included

- Presentation models
- Presentation mapper
- View model provider
- UI-ready pricing view model
- Unit tests
- Barrel exports

---

## Excluded

- Pricing calculations
- Validation
- Policy evaluation
- Quote orchestration
- Provider communication

---

# PricingPresentationMapper

Create:

```typescript
PricingPresentationMapper
```

Responsibilities:

- transform Pricing aggregate
- create summary presentation model
- create breakdown presentation model
- create quote presentation model

Returns immutable presentation models.

Returns `null` for unsuccessful pricing results.

---

# PricingSummaryPresentationModel

Provides high-level commercial information.

Includes:

- total price
- currency
- traveller count
- duration
- destination
- primary commercial message

---

# PricingBreakdownPresentationModel

Provides detailed pricing information.

Includes:

- accommodation subtotal
- experiences subtotal
- taxes
- fees
- discounts
- markups
- commissions
- grand total

No calculations occur within this model.

---

# QuotePresentationModel

Provides quotation-specific information.

Includes:

- quote status
- validity period
- expiry
- commercial notes
- quotation reference

Presentation only.

---

# PricingViewModelProvider

Create:

```typescript
PricingViewModelProvider
```

Responsibilities:

- transform presentation models
- apply UI defaults
- produce immutable PricingViewModel

The provider contains no business logic.

---

# PricingViewModel

Represents the UI-ready pricing model.

Includes:

- summary
- breakdown
- quote
- CTA metadata
- badge styles
- display labels

The model is presentation-specific.

---

# Dependency Rules

The presentation pipeline depends only on:

- Pricing aggregate
- Presentation models

It shall never depend upon:

- providers
- validators
- policies
- calculators

---

# Immutability

All presentation models expose:

- readonly properties
- readonly collections

No mutable references may escape the pipeline.
