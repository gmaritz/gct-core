# Objective

Implement the canonical Booking Integration orchestration layer.

The Booking Integration layer connects the Reservation Capability to external booking providers through provider-independent contracts.

Supplier-specific behaviour shall remain in the Integration Layer.

---

# Booking Gateway

Create

```typescript
BookingGateway
```

Responsibilities

- create booking
- amend booking
- cancel booking
- retrieve booking status

The interface shall remain provider-independent.

---

# Booking Integration Context

Create

```typescript
BookingIntegrationContext
```

Contains

- reservation
- booking request
- integration metadata
- provider selection
- correlation identifiers

Immutable.

---

# Booking Integration Result

Create

```typescript
BookingIntegrationResult
```

Contains

- successful
- provider identifier
- provider booking reference
- reservation status
- errors
- warnings
- metadata

Immutable.

Conforms to APP-001D.

---

# Booking Integration Orchestrator

Create

```typescript
BookingIntegrationOrchestrator
```

Responsibilities

- create immutable BookingIntegrationContext
- invoke BookingGateway
- interpret provider response
- produce BookingIntegrationResult

The orchestrator shall never

- perform HTTP communication
- contain supplier logic
- persist reservations
- execute validation
- evaluate policies

---

# Dependency Injection

Inject

- BookingGateway

The orchestrator shall not instantiate gateway implementations directly.

---

# Failure Behaviour

Business booking failures shall return BookingIntegrationResult.

Unexpected technical failures may raise exceptions.

# Future Evolution

Future milestones may extend Booking Integration with

- multi-provider routing
- retry policies
- compensation workflows
- asynchronous booking confirmation
- event publication
- distributed transaction support

These enhancements shall extend the Booking Integration Orchestrator without changing the Booking Gateway contract.

---

# Milestone Outcome

Upon successful completion, GCT Core shall expose a provider-independent Booking Integration layer that connects the Reservation Capability to external booking systems through immutable contracts and orchestration.

The Reservation Capability remains isolated from supplier implementations while enabling future Hotelbeds and additional provider integrations through the Integration Layer in accordance with INT-000.
