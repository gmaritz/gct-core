# Objective

Implement the canonical Pricing Engine.

The Pricing Engine coordinates the complete pricing workflow while remaining free of pricing rules and calculation logic.

The engine orchestrates existing application components.

It performs no commercial calculations.

---

## Included

- Dependency injection
- Unit tests
- Barrel exports

---

## Excluded

- Policy evaluation logic
- Pricing calculations
- Presentation
- Quote generation
- Provider communication

---

# PricingEngineContext

Create:

```typescript
PricingEngineContext
```

The context represents the immutable state of pricing execution.

Contains:

- pricing request
- validation result
- pricing strategy set
- pricing calculation context
- pricing aggregate
- execution metadata

The context shall be immutable.

Each orchestration stage returns a new enriched context.

---

# PricingEngineResult

Create:

```typescript
PricingEngineResult
```

Contains:

- success indicator
- pricing aggregate
- warnings
- execution metadata

Immutable.

---

# PricingEngine

Create:

```typescript
PricingEngine
```

Responsibilities:

- create PricingEngineContext
- invoke validation pipeline
- invoke policy pipeline
- invoke calculator pipeline
- construct Pricing aggregate
- return PricingEngineResult

The engine shall never:

- perform calculations
- evaluate policies
- validate requests directly
- communicate with providers

---

# Dependency Injection

Inject:

- PricingValidationPipeline
- PricingPolicyPipeline
- PricingCalculatorPipeline

The engine shall construct no dependencies internally.

---

# Execution Flow

## Stage 1

Create PricingEngineContext.

---

## Stage 2

Execute Pricing Validation Pipeline.

Critical validation failures terminate execution.

---

## Stage 3

Execute Pricing Policy Pipeline.

Produces PricingStrategySet.

---

## Stage 4

Execute Pricing Calculator Pipeline.

Produces PricingCalculationResult.

---

## Stage 5

Construct Pricing Aggregate.

---

## Stage 6

Return immutable PricingEngineResult.

---

# Error Handling

Business validation failures shall return unsuccessful results.

Unexpected technical exceptions shall not be converted into business results.

The engine shall preserve fail-fast behaviour for critical validation failures.

---

# Immutability

All engine contracts expose:

- readonly properties
- readonly collections

Execution metadata shall be immutable.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a provider-independent Pricing Engine that orchestrates validation, policy evaluation, pricing calculation and aggregate construction through immutable engine contexts.

The Pricing Engine establishes the orchestration layer of the Pricing Capability while maintaining a strict separation between commercial strategy selection, pricing calculation, aggregate ownership and presentation.
