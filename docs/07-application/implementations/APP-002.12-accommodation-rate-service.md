# Objective

Implement the canonical Accommodation Rate Service.

The service retrieves supplier-independent accommodation rates through the Provider Capability Framework and returns immutable canonical rate results.

The service retrieves rates only.

Pricing, package calculation, commissions and merchandising remain outside the scope of this service.

---

# Architectural Principles

Rates belong to GCT Core.

Providers expose rates.

The Rate Service orchestrates provider execution.

The Rate Service never exposes provider models.

The Rate Service never calculates pricing.

The Rate Service never applies discounts.

The Rate Service never builds packages.

The Rate Service conforms to APP-001A.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a supplier-independent Accommodation Rate Service that conforms to the APP-001A Application Service Pattern and retrieves immutable canonical accommodation rates through the Provider Capability Framework.

Together with the Discovery, Content and Inventory services, the Rate Service completes the four foundational accommodation capabilities. These capabilities form the operational foundation for APP-003 – Package Builder, enabling dynamic journey creation while maintaining a clear separation between supplier data retrieval and higher-level commercial pricing, merchandising and packaging logic.
