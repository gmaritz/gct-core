# Objective

Implement the Hotelbeds Provider Implementation.

The provider implementation orchestrates communication between the Accommodation Engine and the Hotelbeds API while remaining fully compliant with APP-000 and INT-000.

The provider shall implement the AccommodationProvider contract and expose its supported capabilities through the Provider Capability Framework.

---

# Architectural Principle

The Hotelbeds Provider Implementation is an orchestrator.

It shall:

- delegate HTTP communication to the Hotelbeds Client,
- consume Hotelbeds Provider Models,
- invoke the Hotelbeds Mapping Library,
- return canonical Application Result Contracts.

The provider implementation shall contain no presentation logic and no business rules.

# Hotelbeds Client

Create

```typescript
HotelbedsClient
```

Responsibilities

- Execute HTTP requests.
- Manage API communication.
- Return Provider Models.
- Remain stateless.
- Hide HTTP implementation details.

The client shall not perform mapping.

---

# Authentication

Create

```typescript
HotelbedsAuthentication
```

Responsibilities

- Prepare authentication headers.
- Isolate API credential handling.
- Support future API key rotation.

No credentials shall be embedded in source code.

Create

---

# Provider Implementation

Create

```typescript
HotelbedsProvider
```

Responsibilities

- Implement AccommodationProvider.
- Advertise supported capabilities.
- Delegate HTTP to HotelbedsClient.
- Invoke Mapping Library.
- Return Application Results.

The provider implementation shall not contain business logic.

---

# Capability Advertisement

HotelbedsProvider shall advertise supported capabilities through the Provider Capability Framework.

Initially advertise:

- SEARCH
- DETAILS
- CONTENT
- IMAGES
- RATES

Availability support may remain disabled until implemented.

# Milestone Outcome

Upon successful completion, GCT Core shall contain a production-ready Hotelbeds Provider Implementation that integrates cleanly with the Accommodation Engine through the Provider Capability Framework.

The implementation shall orchestrate client communication, model mapping and application result creation while remaining completely isolated from business logic and presentation concerns.

This milestone establishes the first fully functional external provider implementation within GCT Core.
