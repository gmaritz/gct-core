# Objective

Implement the canonical Hotelbeds Provider Model namespace.

Provider Models represent Hotelbeds API contracts.

Provider Models shall remain independent of:

- Canonical Accommodation Models
- Application Results
- View Models
- Domain Models

Provider Models represent Hotelbeds exactly as Hotelbeds defines them.

---

# Architectural Principle

Provider Models are implementation models.

They shall preserve the Hotelbeds API schema.

Provider Models shall never contain business logic.

Provider Models shall never reference GCT Core application models.

---

# Scope

## Included

- Hotelbeds provider namespace
- Provider model namespace
- Core Hotelbeds model contracts
- Barrel exports
- Unit tests

## Excluded

- Mapping
- Provider Adapter
- HTTP Client
- Search execution
- Availability execution
- Accommodation Engine integration

# Design Principles

Models shall:

- Preserve Hotelbeds terminology.
- Preserve Hotelbeds property names where practical.
- Avoid business logic.
- Be immutable.
- Use named exports.
- Compile independently.
