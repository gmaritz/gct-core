# Objective

Implement the canonical Experience Composition Framework.

The framework establishes the application-layer contracts required to compose journey experiences independently of any supplier, catalogue or future Experience Engine.

The framework provides structure, not business behaviour.

---

# Scope

## Included

- Experience composition framework
- Composition context
- Canonical experience models
- Experience classification
- Framework contracts
- Unit tests
- Barrel exports

## Excluded

- Provider integrations
- Pricing
- Reservations
- Journey orchestration
- Supplier catalogues
- Experience Engine implementation

# Milestone Outcome

Upon successful completion, GCT Core shall expose a canonical Experience Composition Framework that defines the immutable contracts, classifications and composition context required for journey experiences.

The framework establishes the architectural foundation for future experience capabilities while remaining completely independent of supplier integrations, presentation, pricing and reservations.
