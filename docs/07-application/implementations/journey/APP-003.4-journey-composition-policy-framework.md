# Objective

Implement the canonical Journey Composition Policy Framework.

The framework provides the reusable business rule infrastructure for Journey Composition.

The framework shall not implement orchestration.

The framework shall not implement provider integrations.

The framework standardises how journey composition policies are registered, resolved, executed and evaluated.

# Canonical Policy Contract

Every Journey policy shall implement

```typescript
JourneyPolicy<
    JourneyCompositionPolicyContext,
    JourneyPolicyResult
>
```

One public operation only:

```typescript
evaluate(context)
```

---

# Journey Policy Context

Create

```typescript
JourneyCompositionPolicyContext
```

Responsibilities

Provide immutable business context required for policy evaluation.

No provider models.

No presentation models.

---

# Journey Policy Result

Create

```typescript
JourneyPolicyResult
```

Minimum properties

- outcome
- priority
- messages

Immutable.

---

# Policy Outcome

Create

```text
ALLOW

DENY

WARNING

IGNORE
```

No string literals.

---

# Policy Priority

Create

```text
CRITICAL

HIGH

NORMAL

LOW
```

Policies execute in deterministic priority order.

---

# Policy Registry

Implement

```typescript
JourneyPolicyRegistry
```

Responsibilities

- register
- unregister
- resolve
- resolveAll

The registry shall expose immutable collections.

Duplicate registrations shall be rejected.

---

# Policy Pipeline

Implement

```typescript
JourneyPolicyPipeline
```

Responsibilities

- resolve registered policies
- execute by priority
- short-circuit on CRITICAL denial
- return immutable results

The pipeline owns execution order.

Policies own evaluation.

The framework shall support future policy families without architectural change.

Examples include:

- AIRecommendationPolicy
- CampaignPolicy
- SupplierPreferencePolicy
- PricingEligibilityPolicy
- ReservationEligibilityPolicy

---

# Milestone Outcome

Upon successful completion, GCT Core shall expose a canonical Journey Composition Policy Framework providing a reusable, stateless and deterministic mechanism for evaluating business policies during journey composition.

The framework establishes policy registration, prioritisation and pipeline execution while remaining independent of providers, pricing, reservations and presentation. It forms the business rule foundation upon which the Journey Composition Service and future composition capabilities will be built.
