# Objective

Implement the canonical Journey Aggregate.

The Journey Aggregate is the central business object of GCT Core.

Every sellable travel experience—whether a private day tour or a multi-day package—shall be represented as a Journey.

The Journey Aggregate is supplier-independent.

It shall not contain provider-specific models.

---

# Architectural Principles

The Journey Aggregate is the Aggregate Root.

The Journey Aggregate owns its supporting value objects.

The Journey Aggregate remains immutable.

The Journey Aggregate shall not contain orchestration logic.

The Journey Aggregate shall not perform pricing.

The Journey Aggregate shall not perform booking.

The Journey Aggregate shall remain reusable across all business capabilities.

- represent a complete journey
- own business state
- expose immutable collections

The Journey Aggregate shall never

- call providers
- retrieve accommodation
- retrieve rates
- calculate pricing
- build itineraries
- create reservations

# Milestone Outcome

Upon successful completion, GCT Core shall contain a canonical Journey Aggregate that serves as the Aggregate Root for every travel experience offered by the platform.

The Journey Aggregate provides a supplier-independent, immutable business model capable of representing both private day tours and multi-day journeys while remaining independent of provider integrations, pricing, reservations and presentation concerns.

This milestone establishes the core domain object upon which the Journey Composition Engine, Package Builder, Homepage Merchandising Engine, Reservation Engine and future AI-assisted journey planning capabilities will be built.
