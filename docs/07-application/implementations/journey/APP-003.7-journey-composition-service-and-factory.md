# Objective

Implement the canonical Journey Composition Service and Journey Factory.

The Journey Composition Service orchestrates all journey composition capabilities.

The Journey Factory constructs a valid Journey Aggregate.

Neither component shall contain provider-specific logic.

Neither component shall contain presentation logic.

# Journey Composition Service

Create

```typescript
JourneyCompositionService
```

Responsibilities

- orchestrate composition
- create composition context
- execute validation pipeline
- execute policy pipeline
- invoke accommodation composition
- invoke experience composition
- invoke Journey Factory
- return JourneyCompositionResult

The service owns orchestration only.

---

# Journey Factory

Create

```typescript
JourneyFactory
```

Responsibilities

- construct Journey Aggregate
- assemble immutable value objects
- enforce aggregate construction invariants
- guarantee valid aggregate creation

The factory shall not perform orchestration.

---

# Journey Composition Context

Create

```typescript
JourneyCompositionContext
```

Purpose

Provide a single immutable context shared across:

- Validation Pipeline
- Policy Pipeline
- Accommodation Composition Adapter
- Experience Composition Framework
- Journey Factory

The context shall be created once and reused throughout the composition workflow.

---

# Journey Composition Result

Create

```typescript
JourneyCompositionResult
```

Conforms to APP-001D.

Contains

- Journey Aggregate
- metadata
- success
- optional warnings

Immutable.

# Dependency Injection

JourneyCompositionService shall receive via constructor injection:

- JourneyValidationPipeline
- JourneyPolicyPipeline
- AccommodationCompositionAdapter
- ExperienceCompositionFramework
- JourneyFactory

The service shall not instantiate collaborators directly.

---

# Factory Responsibilities

The JourneyFactory shall

- create JourneyIdentity
- assign JourneyClassification
- attach JourneyAccommodation
- attach JourneyExperience
- apply JourneyMetadata
- construct immutable collections
- return a valid Journey Aggregate

The factory shall never

- evaluate policies
- perform validation
- call providers
- retrieve data

---

# Service Responsibilities

The JourneyCompositionService shall

- coordinate execution
- honour validation outcomes
- honour policy outcomes
- honour composition failures
- coordinate adapters
- delegate construction to JourneyFactory

The service shall never

- manipulate provider models
- construct Journey manually
- calculate pricing
- perform reservations

---

# Failure Behaviour

Validation failures shall immediately return an unsuccessful JourneyCompositionResult.

Critical policy denial shall terminate composition.

Composition failures shall be isolated where possible.

Unexpected technical failures may raise exceptions.

Expected business outcomes shall be represented through canonical results.

# Future Evolution

The Journey Composition Service shall support future capabilities without architectural change.

Examples

- Dynamic pricing
- AI itinerary optimisation
- Personalisation
- Alternative journey generation
- Multi-supplier accommodation
- Live availability optimisation

These capabilities shall integrate through existing pipelines, adapters and policies.

---

# Milestone Outcome

Upon successful completion, GCT Core shall expose a canonical Journey Composition Service and Journey Factory that coordinate validation, policy evaluation, accommodation composition, experience composition and aggregate construction into a single immutable Journey Aggregate.

The implementation completes the orchestration layer of the Journey Composition Engine while maintaining strict separation between orchestration, business rules, provider integrations, presentation and persistence. It represents the canonical application orchestration pattern for GCT Core.
