# Objective

Implement the canonical Pricing Calculator Framework.

The framework executes commercial pricing calculations through a pipeline of specialised calculators.

Each calculator performs exactly one commercial responsibility.

The framework produces the immutable PricingBreakdown consumed by the Pricing Aggregate.

# PricingCalculationContext

Create:

```typescript
PricingCalculationContext
```

Contains:

- pricing request
- pricing strategy set
- current pricing breakdown
- calculated totals
- currency
- calculation metadata

The context is immutable.

Each calculator returns a new enriched context.

---

# PricingCalculationResult

Create:

```typescript
PricingCalculationResult
```

Contains:

- completed pricing breakdown
- completed totals
- calculation metadata
- warnings

Immutable.

---

# PricingCalculator

Create:

```typescript
PricingCalculator
```

Responsibilities:

- consume PricingCalculationContext
- perform one commercial calculation
- return enriched PricingCalculationContext

A calculator shall never:

- invoke another calculator
- execute policy evaluation
- perform validation
- call providers

---

# Calculator Registry

Create:

```typescript
PricingCalculatorRegistry
```

Responsibilities:

- register calculators
- unregister calculators
- resolve calculators
- deterministic priority ordering

Returned collections shall be immutable.

---

# Calculator Pipeline

Create:

```typescript
PricingCalculatorPipeline
```

Responsibilities:

- resolve registered calculators
- execute in deterministic order
- propagate immutable calculation context
- return PricingCalculationResult

Pipeline orchestration only.

No calculations occur inside the pipeline.

# Dependency Injection

Calculators shall be injected into the registry.

The pipeline shall receive the registry through constructor injection.

No calculator shall instantiate another calculator.

---

# Immutability

Every public contract exposes:

- readonly properties
- readonly collections

Each calculation step returns a new immutable context.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a provider-independent Pricing Calculator Framework that executes commercial pricing through a deterministic pipeline of specialised calculators operating on immutable PricingCalculationContext objects.

The framework establishes the computational core of the Pricing Capability while maintaining a strict separation between commercial strategy selection, pricing calculation, aggregate construction and orchestration.
