# Objective

Implement the canonical Reservation Builder.

The Reservation Builder is responsible for constructing a valid Reservation Aggregate from validated reservation inputs and approved commercial policy outcomes.

The Reservation Builder performs construction only.

It does not validate, evaluate policies, communicate with providers or persist reservations.

---

# Reservation Builder Context

Create

```typescript
ReservationBuilderContext
```

Purpose

Provide a single immutable construction context shared throughout aggregate construction.

The context shall contain

- validated reservation request
- reservation snapshots
- approved policy result
- reservation metadata
- reservation timeline seed

The context is created once and shall remain immutable.

---

# Reservation Builder

Create

```typescript
ReservationBuilder
```

Responsibilities

- construct Reservation Aggregate
- compose immutable snapshots
- initialise reservation timeline
- initialise metadata
- invoke aggregate validation
- return ReservationBuildResult

The builder shall never

- evaluate policies
- perform validation
- calculate pricing
- call providers
- persist reservations

---

# Reservation Build Result

Create

```typescript
ReservationBuildResult
```

Contains

- successful
- reservation
- errors
- warnings
- metadata

Immutable.

Conforms to APP-001D.

---

# Aggregate Validation

After construction the builder shall invoke aggregate validation.

Aggregate validation verifies

- required invariants
- immutable composition
- mandatory snapshots
- construction completeness

Aggregate validation shall not duplicate request validation or policy evaluation.

---

# Dependency Injection

Inject

- ReservationAggregateValidator

The builder shall never instantiate validators directly.

---

# Failure Behaviour

Construction failures shall return ReservationBuildResult.

Business construction failures shall never throw exceptions.

Unexpected technical failures may raise exceptions.

# Milestone Outcome

Upon successful completion, GCT Core shall expose a canonical Reservation Builder that constructs immutable Reservation Aggregates from validated reservation data and approved commercial policy outcomes.

The Reservation Builder establishes the construction stage of the Reservation Capability, completing the transactional pipeline between validation, policy evaluation and service orchestration while maintaining strict separation of concerns and alignment with the Application Layer standards.
