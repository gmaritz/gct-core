# Objective

Implement the canonical Journey Model Library.

The library defines the reusable business concepts owned by the Journey Aggregate.

It establishes the ubiquitous language of GCT Core for all journey-related capabilities.

The library contains immutable supporting models only.

No orchestration or provider logic shall exist.

---

# Architectural Principles

The Journey Aggregate owns these models.

Each model represents a single business concept.

Models remain immutable.

Models remain supplier-independent.

Models remain presentation-independent.

---

# Scope

## Included

- Identity models

- Temporal models
- Experience models
- Marketing models
- Unit tests
- Barrel exports

# Milestone Outcome

Upon successful completion, GCT Core shall possess a complete canonical Journey Model Library defining the immutable business concepts used by every journey-related capability.

The library establishes the ubiquitous language of the platform and forms the foundation for Journey Composition, Homepage Merchandising, Journey Pricing, Reservations, CRM, Analytics and future AI-assisted travel planning while remaining completely independent of supplier integrations and presentation concerns.
