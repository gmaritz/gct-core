# Objective

Establish the Accommodation Engine application namespace.

This milestone introduces the structural foundation for the Accommodation Engine while remaining completely supplier independent.

No accommodation provider shall be implemented during this milestone.

No application behaviour shall change.

No presentation behaviour shall change.

This milestone establishes architecture only.

---

# Architectural Principle

The Accommodation Engine owns accommodation capabilities.

Accommodation providers are implementation details.

The Accommodation Engine shall expose business-oriented contracts rather than supplier-specific contracts.

---

# Accommodation Engine

Create the Accommodation Engine service scaffold.

Example

```typescript
export interface AccommodationEngine {

    search();

}
```

No search implementation is required.

The engine shall compile successfully.

---

# Provider Abstraction

Create a provider abstraction.

Example

```typescript
export interface AccommodationProvider {

    search();

}
```

All future providers shall implement this abstraction.

The abstraction shall remain supplier independent.

# Milestone Outcome

Upon successful completion, GCT Core shall contain a supplier-independent Accommodation Engine application namespace with a clean, extensible architecture ready for multiple accommodation providers.

This milestone establishes the structural foundation for future Accommodation Models, Provider Adapters, Search Services, Ranking Policies and Hotelbeds integration while ensuring the remainder of the platform remains completely unaware of supplier-specific implementations.
