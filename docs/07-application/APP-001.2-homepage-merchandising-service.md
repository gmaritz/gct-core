# Objective

Implement the Homepage Merchandising Service.

The service shall orchestrate homepage merchandising by returning a structured HomepageMerchandisingResult while remaining independent of presentation and supplier integrations.

This milestone introduces application behaviour only.

The Homepage UI shall remain visually unchanged.

---

# Architectural Principle

The Homepage Merchandising Service orchestrates.

It does not:

- render HTML
- create View Models
- access EJS views
- perform server-side rendering
- communicate with UI components

The service returns business objects.

---

# Scope

## Included

- Homepage Merchandising Service implementation
- Homepage Merchandising Result construction
- Dependency injection friendly design
- Placeholder orchestration
- Unit tests

## Excluded

- Hotelbeds integration
- Accommodation Engine
- Package Builder
- View Model Provider changes
- Homepage UI changes
- Journey rotation
- Dynamic ranking

---

# Responsibilities

The Homepage Merchandising Service shall:

- Build HomepageMerchandisingResult.
- Return placeholder editorial content.
- Return placeholder curated journeys.
- Return placeholder metadata.
- Prepare future policy orchestration.

The service shall expose a stable application contract.

---

# Service Contract

```typescript
export interface HomepageMerchandisingService {

    getHomepageMerchandising():

        Promise<HomepageMerchandisingResult>;

}
```

The public contract shall remain stable.

---

# Homepage Merchandising Result

Return a structured result.

Example

```typescript
HomepageMerchandisingResult

    editorial

    journeys

    metadata
```

The service shall not return View Models.

---

# Policy Preparation

Create placeholder policy interfaces.

No policy logic is required.

Create placeholders for:

Policies remain empty until future milestones.

The Homepage Merchandising Service prepares to orchestrate them.

# Milestone Outcome

Upon successful completion, GCT Core shall contain a functional Homepage Merchandising Service that provides a stable business contract for homepage merchandising.

The service shall return placeholder merchandising data while remaining completely independent of presentation, View Models, Hotelbeds, Package Builder and future supplier integrations.

This milestone establishes the orchestration layer that future merchandising policies, campaign management and accommodation integrations will build upon.
