# Objective

Establish the Homepage Merchandising application namespace.

This milestone introduces the application-layer structure that will eventually support homepage merchandising, campaign selection, seasonal priorities and supplier-independent journey curation.

No business behaviour shall change.

No homepage functionality shall change.

This milestone establishes architecture only.

---

# Architectural Principle

The Homepage Merchandising capability shall exist as a dedicated Application Layer capability.

The application layer orchestrates business capabilities.

It does not render presentation.

It does not implement user interface behaviour.

---

# Scope

## Included

- Application namespace
- Folder structure
- Service skeleton
- Result contract
- Barrel exports
- Unit test scaffold

## Excluded

- Merchandising logic
- Business rules
- Hotelbeds integration

- Accommodation Engine integration
- View Model changes

- UI changes

# Application Structure

Create the following namespace.

```text
src/

application/

    merchandising/

        homepage/

            homepage-merchandising.service.ts

            homepage-merchandising-result.ts

            homepage-merchandising.service.test.ts

            index.ts

        models/

            index.ts

        policies/

            index.ts

        index.ts
```

The structure establishes the canonical location for all merchandising-related application services.

---

# Homepage Merchandising Service

Create the service skeleton.

Example

```typescript
export interface HomepageMerchandisingService {

    getHomepageMerchandising();

}
```

No implementation logic is required during this milestone.

The service shall compile successfully.

---

# Homepage Merchandising Result

Create a placeholder application contract.

Example

```typescript
export interface HomepageMerchandisingResult {

    editorial: unknown;

    journeys: unknown[];

    metadata: unknown;

}
```

Strong typing will be introduced during subsequent milestones.

# Models Namespace

Create the models namespace.

No model implementations are required.

Create only the namespace and barrel export.

Purpose

Provide a future location for merchandising-specific application models.

# Policies Namespace

Create the policies namespace.

No policy implementations are required.

Create only the namespace and barrel export.

Purpose

- Seasonal Priority
- Journey Eligibility

- Collection Selection

Upon successful completion, GCT Core shall contain a dedicated Homepage Merchandising application namespace with a clean, extensible architecture ready for future merchandising capabilities.
