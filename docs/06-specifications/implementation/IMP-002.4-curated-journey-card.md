# Objective

Implement the reusable Curated Journey Card component.

The Journey Card represents a curated Go Cape Tours journey.

It is a reusable merchandising component that may appear throughout the platform.

The Journey Card shall communicate aspiration before information.

It should encourage visitors to explore the journey rather than immediately book it.

---

# Architectural Principle

The Journey Card represents a Go Cape Tours journey.

It does not represent:

- a hotel
- supplier inventory
- a booking
- accommodation availability

Accommodation supports the journey.

The journey is always the primary story.

---

# Component Structure

Create a reusable component.

```
views/

partials/

components/

    journey-card.ejs
```

Create stylesheet

```
public/

css/

components/

    journey-card.css
```

The Homepage Showcase shall consume the Journey Card component.

No duplicate Journey Card markup is permitted.

---

# Component Hierarchy

Each Journey Card contains:

```
Journey Image

↓

Journey Name

↓

Destination

↓

Duration

↓

Journey Highlights

↓

Price

↓

Primary CTA

↓

Saving Indicator
```

The order shall remain consistent across the platform.

---

# Journey Image

Purpose

Create an emotional connection before textual content.

Requirements

- Large image
- Landscape
- Rounded corners
- Responsive
- Object-fit cover

Placeholder imagery may be used.

---

# Journey Name

The Journey Name is the most important textual element.

Examples

```
Luxury Winelands Escape

Garden Route Discovery

Cape & Safari Collection
```

Typography

Use DS-001 heading hierarchy.

---

# Destination

Display immediately beneath the Journey Name.

Example

```
Stellenbosch & Franschhoek
```

The destination supports the journey title.

---

# Duration

Example

```
5 Days / 4 Nights
```

Duration shall remain visually understated.

---

# Journey Highlights

Display a concise summary.

Maximum

```
Six highlights
```

Examples

- Private Guide
- Boutique Accommodation
- Wine Tastings
- Scenic Drives
- Gourmet Dining
- Breakfast Included

Highlights should reinforce quality rather than quantity.

---

# Price

Example

```
From

R18 950

per couple
```

Price shall support the journey rather than dominate it.

---

# Primary Call-to-Action

Label

```
View Journey
```

Purpose

Encourage exploration.

The Journey Page performs the selling.

---

# Saving Indicator

Example

```
Save 18%
```

Display adjacent to the CTA.

Savings remain visually understated.

Premium positioning always takes precedence.

---

# Layout

Desktop

Vertical card composition.

The card should breathe.

Avoid compressed layouts.
