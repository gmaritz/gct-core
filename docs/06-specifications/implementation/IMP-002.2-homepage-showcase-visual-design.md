# Objective

Implement the visual presentation of the Homepage Showcase.

This milestone establishes the premium visual identity of the Homepage Showcase by styling both the Editorial Panel and the Curated Journey Collection using the approved Design System (DS-001) and User Experience specification (UX-001).

No dynamic data or supplier integrations shall be introduced during this milestone.

---

# Architectural Principle

The Homepage Showcase is a merchandising experience.

It is **not**:

- a product listing
- a search interface
- a booking interface

Its purpose is to inspire exploration and present the most compelling curated journeys currently available through the Go Cape Tours platform.

The Homepage Showcase represents the commercial heart of the landing page.

---

# Design Philosophy

The Homepage Showcase shall resemble the opening spread of a premium travel magazine.

Visitors should immediately perceive:

- Elegance
- Trust
- Discovery
- Authenticity
- Exclusivity
- Exceptional journeys
- Calm confidence

The interface shall never resemble a discount travel website.

Whitespace is considered a primary design element.

Photography should communicate more than decoration.

---

# Layout Technology

The Homepage Showcase shall use **CSS Grid** for all primary layout composition.

Flexbox may only be used within individual components.

Grid shall define:

- Editorial Panel
- Curated Journey Collection
- Primary Journey Card
- Secondary Journey Cards

Named Grid Areas shall be used to improve maintainability.

Example

```css
.homepage-showcase {

    display: grid;

    grid-template-areas:
        "editorial journeys";

}
```

Avoid unnecessary wrapper elements wherever possible.

- Authentic experiences

---

# Curated Journey Collection

Purpose

Present carefully selected journeys curated by the future Merchandising Engine.

The Homepage Showcase never displays supplier inventory directly.

Every journey represents a Go Cape Tours product.

---

# Curated Journey Hierarchy

Exactly three journeys shall be displayed.

Desktop layout

```
+---------------------------------------------+

Primary Journey

+----------------------+----------------------+

Journey Two            Journey Three

+----------------------+----------------------+
```

Only one journey receives primary visual emphasis.

The remaining two journeys support the primary journey.

The Merchandising Engine will determine which journey occupies the primary position.

The frontend simply renders the supplied View Model.

---

# Curated Journey Composition

The Primary Journey occupies approximately 60% of the Curated Journey Collection.

The two Secondary Journeys share the remaining space equally.

The layout should resemble an editorial publication rather than a catalogue.

The visual hierarchy should naturally guide the visitor through the collection.

# Journey Card Styling

Journey Cards shall include:

- White surface
- Medium border radius
- Medium elevation
- Premium shadow
- Comfortable internal spacing
- Smooth hover elevation

All styling shall consume DS-001 Design Tokens.

No hard-coded design values are permitted.

---

# Journey Imagery

Each Journey Card shall contain a large feature image.

Requirements

- High resolution
- Authentic photography
- Landscape orientation
- Rounded corners
- Object-fit cover
- Responsive sizing

Placeholder imagery may be used.

The imagery should communicate the journey before any text is read.

# Shared Container

The Homepage Showcase shall consume the shared `.container` layout primitive defined by DS-001.

No component-specific page widths shall be introduced.

---

# Visual Restraint

This milestone establishes visual composition only.

Do not introduce effects simply because they are technically possible.

Avoid

- Heavy gradients
- Glass morphism
- Oversized icons
- Decorative ornaments
- Excessive shadows
- Aggressive animations

Photography and whitespace should create the premium impression.

The interface should never compete with the journeys themselves.

---

# Responsive Behaviour

Desktop

Editorial Panel beside Curated Journey Collection.

Tablet

Maintain the editorial relationship wherever practical.

Mobile

Editorial Panel first.

Journey Cards stack vertically.

Spacing remains generous.

Visual hierarchy must remain intact.

---

# Accessibility

Maintain

- Semantic HTML
- Keyboard accessibility
- Visible focus indicators
- Logical reading order
- WCAG AA compliance

---

# Performance

Consume Design Tokens.

Use responsive imagery.

Avoid unnecessary JavaScript.

No layout shift.

Prepare for future merchandising without introducing complexity.

# Milestone Outcome

Upon successful completion, the Homepage Showcase shall present a premium editorial experience that reflects the Go Cape Tours brand while establishing the Curated Journey Collection as the platform's primary merchandising surface.

This milestone creates the visual identity for the homepage and provides the foundation for future merchandising, accommodation galleries, journey rotation and intelligent package presentation without requiring structural redesign.
