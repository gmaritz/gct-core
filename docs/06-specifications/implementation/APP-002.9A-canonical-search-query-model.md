# Objective

Introduce a canonical `AccommodationSearchQuery` model to become the single request object accepted by the Accommodation Discovery Engine.

The query object separates business search criteria from execution context and future platform concerns while providing a stable public API for all consumers of the Accommodation Engine.

This enhancement future-proofs the Discovery Engine without changing its business behaviour.

---

# Architectural Principle

The Discovery Engine shall receive one immutable query object.

The query encapsulates:

- what is being searched
- why it is being searched
- how the search is being executed

Supplier-specific request models shall never be exposed outside provider implementations.

# AccommodationSearchQuery

Create

```typescript
AccommodationSearchQuery
```

The query becomes the canonical request contract.

```typescript
interface AccommodationSearchQuery {

    readonly criteria:
        AccommodationSearchCriteria;

    readonly context:
        AccommodationSearchContext;

}
```

The query shall be immutable.

```typescript
interface AccommodationSearchContext {

        AccommodationSearchSource;
```

# Discovery Engine

Update the public interface.

Replace

```typescript
discover(
    criteria:
        AccommodationSearchCriteria
)
```

with

```typescript
discover(
    query:
        AccommodationSearchQuery
)
```

The Discovery Engine shall not accept raw criteria directly.




This enables future:

- analytics
- campaign reporting
- search optimisation
- merchandising
- diagnostics
- observability

# Milestone Outcome

Upon successful completion, the Accommodation Discovery Engine shall expose a single immutable `AccommodationSearchQuery` contract that cleanly separates business search criteria from execution context.

The introduction of the typed `AccommodationSearchSource` enumeration establishes a canonical mechanism for identifying the origin of every accommodation search, enabling future analytics, merchandising, personalisation, diagnostics and multi-channel orchestration without requiring changes to the Discovery Engine public API.

This milestone finalises the canonical public request contract for the Accommodation Engine and prepares GCT Core for Package Builder, Homepage Merchandising, internal administration tools and future API integrations.
