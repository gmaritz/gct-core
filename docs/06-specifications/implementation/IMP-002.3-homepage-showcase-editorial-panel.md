# Objective

Implement the Editorial Panel of the Homepage Showcase.

The Editorial Panel establishes the voice of Go Cape Tours.

It introduces visitors to the philosophy behind the brand while encouraging them to explore the curated journeys presented alongside it.

The Editorial Panel is intentionally calm, refined and timeless.

It should never resemble promotional marketing copy.

---

# Architectural Principle

The Editorial Panel communicates identity.

The Curated Journey Collection communicates opportunity.

The two components complement one another but remain independent.

---

# Scope

## Included

- Editorial content hierarchy
- Typography
- CTA hierarchy
- Visual rhythm
- Responsive refinement
- White-space composition
- Editorial styling

## Excluded

- Journey cards
- Dynamic merchandising
- Journey rotation
- Accommodation gallery
- Animations
- CMS integration

---

# Purpose

The Editorial Panel should answer:

Why travel with Go Cape Tours?

It should inspire confidence before encouraging exploration.

The visitor should feel that every journey has already been thoughtfully curated.

---

# Content Hierarchy

The Editorial Panel consists of:

```
Eyebrow

↓

Primary Heading

↓

Supporting Narrative

↓

Primary CTA

↓

Secondary CTA
```

No additional promotional elements shall be introduced.

---

# Eyebrow

The Eyebrow introduces the editorial narrative.

Suggested placeholder

```
Curated Private Journeys
```

The Eyebrow shall use the brand accent colour.

It should remain understated.

---

# Primary Heading

Suggested placeholder

```
Discover South Africa Through Carefully Curated Journeys.
```

Requirements

- Cormorant Garamond
- Maximum two lines
- Strong editorial presence
- Comfortable line height

The heading is the most visually dominant text element.

---

# Supporting Narrative

Suggested placeholder

```
From the vineyards of Stellenbosch to the coastline of the Garden Route, every Go Cape Tours journey combines exceptional accommodation, authentic experiences and local expertise to create unforgettable memories.
```

Requirements

- Maximum three short paragraphs or one concise paragraph
- Comfortable reading width
- High readability
- Editorial tone

Avoid sales language.

---

# Primary Call-to-Action

Label

```
Explore Experiences
```

Purpose

Guide visitors toward the curated experiences catalogue.

The CTA should feel inviting rather than urgent.

Use the shared primary button component.

---

# Secondary Call-to-Action

Label

```
Plan Your Journey
```

Purpose

Encourage visitors seeking a bespoke experience.

Use the shared secondary button component.

The secondary CTA should never visually compete with the primary CTA.

---

# Visual Composition

The Editorial Panel shall rely on:

- Generous whitespace
- Strong typography
- Limited colour palette
- Clear hierarchy
- Consistent spacing

No decorative graphics shall be introduced.

The photography in the Curated Journey Collection provides the visual storytelling.

---

# Reading Width

Maximum text width

```
40–45 characters per line (approximately 32–36rem)
```

Avoid excessively wide paragraphs.

---

# Colour Usage

Typography

Use DS-001 text tokens.

Eyebrow

Use the brand colour token.

Background

Transparent.

The Homepage Showcase background remains responsible for the overall presentation.

---

# Button Layout

Desktop

Buttons appear horizontally.

Mobile

Buttons stack vertically with consistent spacing.

---

# Responsive Behaviour

Desktop

Content remains vertically centred within the Editorial Panel.

Tablet

Maintain visual hierarchy with proportional scaling.

Mobile

- Centre-align content
- Maintain generous spacing
- Stack CTAs vertically

---

# Accessibility

Maintain

- Semantic HTML
- Single H1
- Logical heading hierarchy
- Keyboard accessible CTAs
- Visible focus indicators
- WCAG AA compliance

---

# Performance

Consume DS-001 Design Tokens.

Reuse shared button components.

No additional JavaScript shall be introduced.

---

# CSS Responsibilities

homepage-showcase.css shall implement:

- Editorial typography
- Eyebrow styling
- Narrative spacing
- CTA spacing
- Responsive typography
- Reading width
- Vertical alignment

No behavioural logic shall be introduced.

---

# JavaScript Responsibilities

homepage-showcase.js remains unchanged.
